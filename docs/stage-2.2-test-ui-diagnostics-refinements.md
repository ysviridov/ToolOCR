# Stage 2.2 — улучшенная диагностическая панель Test UI

## Назначение

Диагностическое окно Test UI должно быть пригодно для визуального контроля без чтения большого JSON. Полный JSON сохраняется как технический источник истины и доступен отдельными кнопками `Показать JSON` и `Скачать JSON`.

## Адаптивная ширина

Верхний уровень диагностики сохраняет три колонки:

```text
Параметр | Значение | Описание
```

Вложенные структуры не наследуют фиксированное распределение ширины верхней таблицы. Для них используется `table-layout:auto` и собственные минимальные ширины. Это предотвращает каскадное сжатие при структурах вида:

```text
digits -> digit -> top3 -> candidate
```

## CNN почтового индекса

Поле `test_ui_postcode_ocr.digits` отображается специальным плоским представлением из шести карточек `D1...D6`. Для каждой позиции показываются:

- выбранная цифра;
- статус;
- confidence;
- фактически использованный engine;
- причина ошибки, если есть;
- TOP-3 кандидатов в компактной таблице;
- сворачиваемая краткая диагностика preprocessing.

Это только UI-представление. Backend payload и JSON export не изменяются.

## Описания параметров

Для основных полей layout, orientation, format validation, ROI и ONNX runtime используются конкретные человекочитаемые описания со ссылкой на профильную документацию.

Для менее распространённых полей действует семантический fallback по имени параметра:

- `*_ms` — длительность этапа в миллисекундах;
- `*_px` — размер или координата в пикселях;
- `*_ratio` — нормированное отношение;
- `*_count` — количество элементов;
- `*_status` — состояние этапа;
- `*_score` — оценка гипотезы;
- `*_confidence` — диагностическая уверенность;
- `*_error` — величина ошибки;
- `*_bbox` — прямоугольная область.

Fallback не должен выводить техническую фразу вида «параметр из diagnostic payload». Его задача — объяснить смысл параметра оператору или разработчику.

## Confidence CNN

Softmax confidence в диагностике не трактуется как гарантированная вероятность правильной сортировки. Даже высокое значение может соответствовать ошибочной классификации. Поэтому описания `confidence`, `min_digit_confidence` и `TOP-3` явно подчёркивают их диагностическую роль.
